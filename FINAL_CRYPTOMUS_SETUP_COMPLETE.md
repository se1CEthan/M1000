### **Quick Setup** (10 minutes total):

#### 1. **Add Demo Products** (2 minutes):
```bash
# In Supabase SQL Editor, run:
scripts/add-demo-products.sql
```

#### 2. **Verify Setup** (2 minutes):
```bash
# Test the configuration
npm run setup-cryptomus
```

#### 3. **Build for Production** (3 minutes):
