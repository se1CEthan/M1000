# SelTech Online - Beam.ai Inspired UI/UX Redesign

## Design System Overview (Beam.ai Style)

### Color Palette
- **Primary Purple**: #8B5CF6 (Violet)
- **Primary Blue**: #3B82F6 (Blue)
- **Accent Pink**: #EC4899 (Pink)
- **Accent Cyan**: #06B6D4 (Cyan)
- **Background Dark**: #0F172A (Slate 900)
- **Surface**: #1E293B (Slate 800)
- **Text Primary**: #F8FAFC (Slate 50)
- **Text Secondary**: #94A3B8 (Slate 400)

### Key Features
1. **Dark Theme**: Deep dark backgrounds with vibrant accents
2. **Glassmorphism**: Frosted glass effects with blur
3. **Gradient Meshes**: Animated gradient backgrounds
4. **Smooth Animations**: Framer Motion style animations
5. **Glow Effects**: Neon glows on interactive elements
6. **Floating Elements**: Subtle floating animations
7. **Blur Effects**: Backdrop blur on cards and modals
8. **Gradient Text**: Animated gradient text effects

### Animation Types
- Fade in/out with scale
- Slide in from directions
- Stagger animations for lists
- Hover lift effects
- Glow pulse on focus
- Smooth page transitions
- Parallax scrolling effects
- Morphing shapes
