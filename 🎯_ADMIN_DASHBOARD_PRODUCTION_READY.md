## 🚀 How to Use (Production Guide)

### Access Admin Dashboard
1. **Login as admin** - Use se1cethan@gmail.com (set as admin in database)
2. **Navigate to /admin** - Go to the admin dashboard URL
3. **View overview** - See pending reviews and statistics

### Review Products
1. **Go to Products tab** - See all submitted products
2. **Filter by status** - View pending, approved, or rejected products
3. **Click "Review"** - Open detailed product review
4. **Check all criteria**:
   - ✅ Product description is clear and accurate
   - ✅ Price is reasonable for the value provided
   - ✅ Demo URL works (if provided)
   - ✅ Documentation is helpful (if provided)
   - ✅ Product file downloads correctly
   - ✅ No malicious or inappropriate content
   - ✅ Follows platform policies

### Approve Products
1. **Add review notes** (optional) - Internal notes about the product
2. **Click "Approve Product"** - Product goes live immediately
3. **Product appears on marketplace** - Buyers can now purchase

### Reject Products
1. **Add rejection reason** (required) - Explain why it's rejected
2. **Click "Reject Product"** - Product is blocked from marketplace
3. **Seller gets notification** - They can see the rejection reason

### Quick Actions
- **Bulk approve** - Use quick approve buttons in the table
- **Bulk reject** - Use quick reject buttons in the table
- **Search products** - Find specific products quickly
- **Filter by category** - Review products by type
